# MISSION: BUILD "AGRISPECTRA FLOW & FIELD" (UNIFIED PRECISION AGRICULTURE APP)

Develop a complete, production-grade, full-stack mobile-responsive application with a modern, high-end UI/UX, integrated with **Firebase Data Connect (PostgreSQL Relational Database)** and backend services.

The application unifies two agricultural hardware systems:
1. AgriSpectra Handheld Leaf-Clip Spectroscopy (350–1100 nm spectral reflectance, edge ML plant health diagnostics).
2. Hierarchical 1-Acre 6-Zone Smart Irrigation (FDR soil moisture telemetry and DC latching solenoid valve controls).

---

## 1. TECH STACK SPECIFICATIONS
- **Frontend:** Modern Mobile-First PWA (HTML5 / Tailwind CSS / Modern ES6+ or React/Next.js) with ultra-modern Bento-Grid layout, fluid micro-interactions, dark/light sun-glare modes, and zero outdated enterprise UI aesthetics.
- **Relational Database:** **Firebase Data Connect with Managed PostgreSQL (Cloud SQL)**:
  - Strong relational data modeling with strict foreign keys, cascade rules, and indexes.
  - Type-safe GraphQL queries and mutations generated by Firebase Data Connect.
  - Strict ACID transaction guarantees for valve state transitions and water volume accounting.
- **Backend & Automation:** Firebase Cloud Functions / Node.js or Python backend with Firebase Admin SDK for closed-loop scheduling, event triggers, and MQTT ingestion.
- **Hardware Simulation & Connectivity:** Web Bluetooth API (BLE 5.0 GATT profile) simulation + Mock MQTT telemetry listener for soil moisture & valve actuators.

## 3. CORE FUNCTIONAL MODULES

### Module A: Leaf Spectroscopy & Edge Chemometrics
- Connect via simulated Web Bluetooth / USB-OTG to the leaf-clip sensor.
- Calibration sequence: Dark current reference test + 99% PTFE White disc calibration.
- Process spectral vectors (350–1100 nm) to display 5 farmer decisions:
  1. Crop Vitality Score (0–100 gauge).
  2. Nitrogen & Fertilizer Prescription (e.g., "15 kg/acre Urea needed before next watering").
  3. Irrigation Need Countdown (e.g., "Water in 36 hours").
  4. Pre-Symptomatic Disease Alert (e.g., "Early Powdery Mildew detected with 82% confidence").
  5. Harvest Window Predictor (e.g., "Maturity 72% – Peak harvest in 14 days").

### Module B: 6-Zone Hydraulic Valve & Soil Monitoring
- Zone Control: Independent controls for Gates G1 through G6.
- Solenoid Valve Pulse Actuation: Send +12V pulse to open (with configurable timer, e.g., 20 min) and reverse -12V pulse to close.
- Soil FDR Probes: Real-time volumetric water content (VWC %) and temperature per plot.
- Flow & Safety: Mainline pressure (Bar), daily consumed liters, and emergency 1-tap "Shut Off All Valves".

### Module C: Closed-Loop Leaf-to-Valve Synergy
- When a leaf scan in Plot X detects water stress / turgor loss, query the relational database for Plot X's latest FDR moisture reading.
- Auto-generate a Smart Action Card: "Plot 2 leaf stress confirmed by 13% soil moisture. Open Gate 2 valve for 25 minutes? [APPROVE / DISMISS]".

## 4. RELATIONAL DATABASE SCHEMA (FIREBASE DATA CONNECT / POSTGRESQL)

```sql
-- Farms Table
CREATE TABLE farms (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    name VARCHAR(255) NOT NULL,
    total_area_acres NUMERIC(5,2) DEFAULT 1.00,
    latitude NUMERIC(10,7),
    longitude NUMERIC(10,7),
    created_at TIMESTAMPTZ DEFAULT NOW()
);

-- Plots Table (6 micro-zones per 1-acre farm)
CREATE TABLE plots (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    farm_id UUID NOT NULL REFERENCES farms(id) ON DELETE CASCADE,
    plot_number INT NOT NULL CHECK (plot_number BETWEEN 1 AND 6),
    crop_name VARCHAR(100) NOT NULL,
    growth_stage VARCHAR(50) NOT NULL,
    target_vwc_min NUMERIC(5,2) DEFAULT 20.00,
    target_vwc_max NUMERIC(5,2) DEFAULT 35.00,
    created_at TIMESTAMPTZ DEFAULT NOW(),
    UNIQUE(farm_id, plot_number)
);

-- Valve Actuators Table (G1 to G6)
CREATE TABLE valves (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    plot_id UUID NOT NULL REFERENCES plots(id) ON DELETE CASCADE,
    gate_identifier VARCHAR(10) NOT NULL, -- 'G1', 'G2', etc.
    state VARCHAR(20) NOT NULL DEFAULT 'CLOSED' CHECK (state IN ('OPEN', 'CLOSED', 'FAULT')),
    pulse_voltage INT DEFAULT 12,
    current_flow_rate_lph NUMERIC(8,2) DEFAULT 0.00,
    last_actuated_at TIMESTAMPTZ,
    timer_expires_at TIMESTAMPTZ
);

-- Soil FDR Probes Telemetry Table
CREATE TABLE soil_sensor_readings (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    plot_id UUID NOT NULL REFERENCES plots(id) ON DELETE CASCADE,
    probe_identifier VARCHAR(50) NOT NULL,
    vwc_percent NUMERIC(5,2) NOT NULL, -- Volumetric Water Content
    soil_temp_celsius NUMERIC(5,2) NOT NULL,
    salinity_ec_ds_m NUMERIC(5,2),
    recorded_at TIMESTAMPTZ DEFAULT NOW()
);
CREATE INDEX idx_soil_readings_plot_time ON soil_sensor_readings(plot_id, recorded_at DESC);

-- Leaf Spectroscopy Scans Table
CREATE TABLE leaf_scans (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    plot_id UUID NOT NULL REFERENCES plots(id) ON DELETE CASCADE,
    vitality_score INT NOT NULL CHECK (vitality_score BETWEEN 0 AND 100),
    leaf_water_index NUMERIC(6,4) NOT NULL,
    nitrogen_prescription_kg_per_acre NUMERIC(6,2) DEFAULT 0.00,
    pathogen_name VARCHAR(150),
    pathogen_risk_percent INT CHECK (pathogen_risk_percent BETWEEN 0 AND 100),
    preventative_action TEXT,
    scanned_at TIMESTAMPTZ DEFAULT NOW()
);
CREATE INDEX idx_leaf_scans_plot_time ON leaf_scans(plot_id, scanned_at DESC);

-- Irrigation Audit Logs (ACID Water Volume Ledger)
CREATE TABLE irrigation_logs (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    valve_id UUID NOT NULL REFERENCES valves(id) ON DELETE CASCADE,
    plot_id UUID NOT NULL REFERENCES plots(id) ON DELETE CASCADE,
    action VARCHAR(20) NOT NULL CHECK (action IN ('OPEN', 'CLOSE', 'EMERGENCY_SHUTOFF')),
    duration_minutes NUMERIC(6,2),
    liters_delivered NUMERIC(10,2) DEFAULT 0.00,
    triggered_by VARCHAR(50) NOT NULL CHECK (triggered_by IN ('MANUAL_TOUCH', 'CLOSED_LOOP_SPECTROSCOPY', 'OFFLINE_FAILSAFE')),
    timestamp TIMESTAMPTZ DEFAULT NOW()
);
```
